# 🎉 久坐提醒助手 v1.1 - 功能更新说明

## ✨ 新增功能

### 1. 自定义提醒间隔 ⏰

**位置：** 菜单栏 → "设置提醒间隔"

**功能：**
- 预设选项：30分钟、45分钟、1小时、2小时
- 自定义选项：输入任意分钟数（1-480分钟）
- 当前选中的间隔会显示勾选标记
- 修改后立即生效，计时器自动重置

**使用方法：**
1. 点击菜单栏图标
2. 选择"设置提醒间隔"
3. 选择预设时间或点击"自定义..."输入
4. 设置完成后会显示通知确认

**配置保存：**
- 配置文件：`~/.sedentary_reminder/config.json`
- 下次启动自动加载上次的设置

---

### 2. 使用统计 📊

**位置：** 菜单栏 → "查看统计"

**统计内容：**

**今日数据：**
- 提醒次数：今天收到了多少次提醒
- 活动次数：今天起来活动了多少次

**累计数据：**
- 总提醒次数：从安装以来的总提醒次数
- 总活动次数：从安装以来起来活动的总次数
- 总忽略次数：提醒后仍然坐着的次数

**活动率：**
- 计算公式：活动次数 / 提醒次数 × 100%
- 反映你对久坐提醒的响应程度

**数据说明：**
- 检测到无人时 → 记录为"活动"
- 弹出提醒时 → 记录为"提醒"
- 提醒后仍坐着 → 记录为"忽略"
- 每天0点自动重置今日数据

**数据文件：**
- 统计文件：`~/.sedentary_reminder/stats.json`
- 保留最近100条历史记录

### 3. 优化的提醒方式 💬

**旧版提醒：**
```
❌ 强制性对话框
❌ 需要输入推迟时间
❌ 操作复杂
```

**新版提醒：**
```
✅ 友好的提示语："检测到您已久坐 ⏰ 建议起来活动一下，保护颈椎和眼睛～"
✅ 三个清晰的选项：
   • "我知道了" - 确认已看到，30秒后再次确认
   • "10分钟后提醒" - 推迟10分钟
   • "跳过本次" - 跳过本次提醒，直接开始下一轮倒计时
✅ 不强制，给用户更多选择
```

**按钮说明：**

| 按钮 | 行为 | 统计记录 |
|------|------|---------|
| 我知道了 | 30秒后再次检测，如果还在就再次提醒 | 记录提醒 |
| 10分钟后提醒 | 延迟10分钟后再检测 | 记录提醒 |
| 跳过本次 | 直接开始下一轮倒计时 | 记录忽略 |

## 📁 文件结构

```
~/.sedentary_reminder/
├── config.json          # 配置文件
│   ├── interval_seconds # 提醒间隔（秒）
│   ├── show_welcome     # 是否显示欢迎提示

    ├── today_reminders  # 今日提醒次数

    └── history[]        # 历史记录（最近100条）

└── app.log              # 日志文件
```

## 💡 使用建议

### 提醒间隔设置
- **办公室工作：** 1小时（推荐）
- **在家办公：** 45分钟
- **长时间专注：** 2小时
- **测试调试：** 5-10分钟

### 提高活动率
- 收到提醒立即起来活动
- 不要频繁点击"跳过本次"
- 定期查看统计数据，激励自己
- 目标：活动率 > 80%

### 健康建议
- 每次活动至少5分钟
- 简单拉伸、走动、喝水
- 远眺放松眼睛
- 活动颈椎和肩膀

## 🐛 已知问题

### 检测准确性
- 光线太暗可能检测不到
- 侧脸、低头可能检测不到
- 戴口罩可能影响检测

### 解决方法
- 保持良好的光线
- 正面面对摄像头
- 调整摄像头角度
