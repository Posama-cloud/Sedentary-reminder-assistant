# 久坐提醒助手 macOS 打包故障排查记录

## 问题时间线

### 第一次崩溃：摄像头权限问题
**现象**：应用启动即崩溃
**错误信息**：
```
Termination Reason: TCC, Code 0
This app has crashed because it attempted to access privacy-sensitive data 
without a usage description. The app's Info.plist must contain an 
NSCameraUsageDescription key.
```

**解决方案**：
在 PyInstaller spec 文件的 `info_plist` 中添加：
```python
'NSCameraUsageDescription': '本应用需要访问摄像头来检测您是否在电脑前，以便准确提醒您休息。摄像头仅用于本地检测，不会上传或保存任何图像。'
```

### 第二次崩溃：应用注册失败 ⭐ **关键问题**
**现象**：添加摄像头权限后仍然崩溃
**错误信息**：
```
"termination" : {
  "indicator":"Abort trap: 6"
}
"asi" : {
  "libsystem_c.dylib":["abort() called"]
}
```

**崩溃堆栈**：
```
___RegisterApplication_block_invoke  ← 崩溃点
GetCurrentProcess
-[NSMenuBarPresentationInstance _getAggregateUIMode:withOptions:]
-[NSMenuItem setTitle:]
-[NSMenuItem _configureAsSeparatorItem]
+[NSMenuItem separatorItem]
```

**根本原因**：
- 应用是菜单栏应用（没有 Dock 图标）
- 但 Info.plist 中缺少 `LSUIElement` 配置
- macOS 在注册应用时失败
- 创建菜单项时触发 abort

**解决方案**：
在 PyInstaller spec 文件的 `info_plist` 中添加：
```python
'LSUIElement': True,  # 菜单栏应用，不在 Dock 显示
```

## 关键知识点

### LSUIElement vs LSBackgroundOnly

| 配置 | 用途 | Dock 图标 | 菜单栏 | 窗口 |
|------|------|-----------|--------|------|
| 无配置 | 普通应用 | ✅ | ✅ | ✅ |
| LSUIElement | 菜单栏应用 | ❌ | ✅ | ✅ |
| LSBackgroundOnly | 纯后台应用 | ❌ | ❌ | ❌ |

**本应用使用 LSUIElement**，因为：
- 需要在菜单栏显示图标
- 需要显示提醒对话框
- 不需要在 Dock 显示

### macOS 应用注册流程

1. 应用启动
2. macOS 调用 `RegisterApplication`
3. 检查 Info.plist 配置
4. 根据 LSUIElement/LSBackgroundOnly 决定显示方式
5. 如果配置不匹配实际行为 → 崩溃

**本应用的问题**：
- 代码中创建了菜单栏图标（NSStatusBar）
- 但 Info.plist 中没有声明是菜单栏应用
- macOS 认为这是普通应用，但又找不到主窗口
- 导致 `RegisterApplication` 失败

## 经验教训

1. **PyInstaller 打包 macOS 菜单栏应用必须配置 LSUIElement**
2. **崩溃日志中的堆栈信息比错误描述更重要**
3. **macOS 应用类型（普通/菜单栏/后台）必须在 Info.plist 中明确声明**
4. **权限配置（NSCameraUsageDescription）和应用类型配置（LSUIElement）都是必需的**
