## ⚠️ 常见问题排查

### **问题 1：程序启动后立即崩溃**

**可能原因：**
- 依赖包未安装或版本不对

**解决方法：**
```bash
cd /Users/a1/PythonProject
source .venv/bin/activate
pip install --upgrade opencv-python rumps
```

---

### **问题 2：摄像头打开失败**

**症状：**
- 弹窗提示"无法打开摄像头"
- 日志显示 "无法打开摄像头"

**可能原因：**
1. 没有授予摄像头权限
2. 摄像头被其他应用占用
3. 摄像头硬件故障

**解决方法：**
1. 检查权限：
   - 打开"系统设置" > "隐私与安全性" > "摄像头"
   - 确保 Terminal 或 Python 有权限
   - 如果没有，删除权限记录后重新运行：
     ```bash
     tccutil reset Camera
     ```

2. 检查是否被占用：
   - 关闭所有使用摄像头的应用（Zoom、FaceTime 等）
   - 重新运行程序

3. 测试摄像头：
   ```bash
   python -c "import cv2; cap = cv2.VideoCapture(0); print('摄像头状态:', cap.isOpened()); cap.release()"
   ```

---

### **问题 3：检测不到人脸**

**症状：**
- 明明坐在摄像头前，但检测结果是"未检测到人"
- 日志显示所有帧都是"未检测到人脸"

**可能原因：**
1. 光线太暗
2. 距离摄像头太远
3. 脸部被遮挡（口罩、手、头发等）
4. 侧脸或低头

**解决方法：**
1. 改善光线条件
2. 靠近摄像头（建议距离 50-100cm）
3. 正面面对摄像头
4. 移除遮挡物

**调试方法：**
- 使用"立即测试检测"功能多次测试
- 查看日志中每一帧的检测结果
- 如果 5 帧中有 3 帧以上检测到人脸，就会判定为"有人"

---

### **问题 4：提醒弹窗不出现**

**症状：**
- 倒计时结束后没有弹窗
- 日志显示 "AppleScript 执行失败"

**可能原因：**
- macOS 自动化权限未授予

**解决方法：**
1. 打开"系统设置" > "隐私与安全性" > "自动化"
2. 确保 Terminal 或 Python 有权限控制"系统事件"
3. 重新运行程序

---

### **问题 5：程序运行一段时间后卡住**

**症状：**
- 菜单栏倒计时不更新
- 点击菜单没有反应

**可能原因：**
- 线程死锁或异常

**解决方法：**
1. 查看日志文件，找到最后的错误信息
2. 强制退出程序：
   ```bash
   killall Python
   ```
3. 重新启动程序
