### 已解决的问题

1. ✅ **摄像头权限崩溃**
   - 问题：应用启动时因缺少 NSCameraUsageDescription 而崩溃
   - 解决：在 Info.plist 中添加摄像头使用说明
   - 验证：使用 `plutil -p` 确认配置正确

2. ✅ **应用注册失败崩溃** ⭐ **关键问题**
   - 问题：`RegisterApplication` 失败，创建菜单项时崩溃
   - 原因：菜单栏应用缺少 `LSUIElement` 配置
   - 解决：在 Info.plist 中添加 `LSUIElement: true`
   - 验证：应用成功启动并在菜单栏显示

3. ✅ **代码签名**
   - 问题：macOS 安全机制要求应用签名
   - 解决：使用 ad-hoc 签名并添加摄像头权限 entitlement
   - 命令：`codesign --force --deep --sign - --entitlements <file>`

4. ✅ **打包模式**
   - 问题：onefile 模式与 .app bundle 不兼容
   - 解决：改用 onedir 模式（PyInstaller 推荐）
   - 结果：生成标准的 macOS 应用结构

## 快速重新打包

如需重新打包，执行以下命令：

```bash
cd /Users/a1/PythonProject
rm -rf build dist
source .venv/bin/activate
pyinstaller --noconfirm 久坐提醒助手.spec

# 签名
cd dist
xattr -cr "久坐提醒助手.app"
codesign --force --deep --sign - --entitlements /dev/stdin "久坐提醒助手.app" <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>com.apple.security.device.camera</key>
    <true/>
</dict>
</plist>
EOF

# 打包
zip -r ../久坐提醒助手_v1.1_fixed.zip "久坐提醒助手.app"
```
