## 🐛 常见问题

### 问题1：配置文件不存在
```bash
# 手动创建
mkdir -p ~/.sedentary_reminder
echo '{"interval_seconds": 3600, "show_welcome": true}' > ~/.sedentary_reminder/config.json
```

### 问题2：统计数据异常
```bash
# 重置统计数据
rm ~/.sedentary_reminder/stats.json
# 重启程序
```

### 问题3：提醒对话框不显示
- 检查日志中的错误信息
- 确认 AppleScript 权限
- 查看"系统设置 > 隐私与安全性 > 自动化"
