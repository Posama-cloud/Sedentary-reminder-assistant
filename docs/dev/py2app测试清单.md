# py2app 打包测试清单

## 打包前检查

- [ ] 已安装 py2app: `pip install py2app`
- [ ] 已安装所有依赖: `pip install -r requirements.txt`
- [ ] image_0.png 文件存在
- [ ] maincharacter.py 可以正常运行

## 打包测试

### 1. 开发模式测试（快速）

```bash
# 清理
rm -rf build dist

# 打包
python setup.py py2app -A

# 测试运行
open dist/久坐提醒助手.app
```

**检查项：**
- [ ] 应用可以启动
- [ ] 菜单栏显示图标
- [ ] 摄像头权限请求正常
- [ ] 人脸检测功能正常
- [ ] 提醒功能正常

### 2. 发布模式测试（完整）

```bash
# 清理
rm -rf build dist

# 打包
python setup.py py2app

# 或使用脚本
./build.sh
```

**检查项：**
- [ ] 打包成功，无错误
- [ ] 应用大小合理（150-200 MB）
- [ ] 应用可以启动
- [ ] 所有功能正常

### 3. 独立性测试

在**另一台 Mac** 或**新用户账户**测试：

```bash
# 拷贝应用到其他位置
cp -r dist/久坐提醒助手.app ~/Desktop/

# 运行
open ~/Desktop/久坐提醒助手.app
```

**检查项：**
- [ ] 不需要安装 Python 即可运行
- [ ] 不需要安装依赖即可运行
- [ ] 摄像头权限请求正常
- [ ] 所有功能正常

```bash

```

### DMG 分发（可选）

```bash
# 需要安装 create-dmg
brew install create-dmg

# 创建 DMG
create-dmg \
  --volname "久坐提醒助手" \
  --window-size 600 400 \
  --icon-size 100 \
  --app-drop-link 450 200 \
  久坐提醒助手_v1.1.dmg \
  dist/久坐提醒助手.app
```

- [ ] DMG 创建成功
